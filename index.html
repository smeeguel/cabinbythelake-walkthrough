Cabin Loop Atlas

A walkthrough planner for Cabin by the Lake 0.62d

What this is

A reference tool. It reads the game's own scripts and works out which corruption toggles to switch on before a run, and the exact choices to make during it, for any scene, mail or collection dot you want to unlock.

It is text only: no images, no audio, no game files, and no part of the game itself.
